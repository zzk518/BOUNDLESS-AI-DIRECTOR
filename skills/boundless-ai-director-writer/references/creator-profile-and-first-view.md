# 创作者档案与首刷体验

## 创作者偏好档案

只记录用户明确选择或作品反复显示的证据。没有持久存储时，称为“本项目档案”，不要声称永久记住。

```yaml
creator_profile:
  positive_taste: []        # 喜欢的作品/段落 + 喜欢的具体机制
  recurring_material: []    # 反复出现的生活、职业、地域、人物
  dialogue_texture: []      # 方言、停顿、冷/热、解释容忍度
  ending_preference: []
  ambiguity_tolerance: low|medium|high
  genre_appetite: []
  production_bias: []       # 低成本、少场景、演员能力等
  hard_no: []               # 禁区 + 失败原因
  evidence: []              # 来源：用户选择/原稿/明确指示
```

新偏好与旧偏好冲突时保留两条，标注项目范围，不静默覆盖。

## 首次观看体验图

按场景或序列维护：

| 时段 | 观众知道 | 正在问 | 当前预测 | 情绪/身体感受 | 新证据 | 重新理解 | 回报/欠账 |
|---|---|---|---|---|---|---|---|

### 规则

- “不知道”不是悬念；观众必须知道自己正在等什么。
- 新证据要改变预测、人物判断或行动代价之一。
- 误导必须由真实可见事实支持，不能靠故意省略人物必然会说/做的事。
- 每个主要问题登记最迟回报窗口；决定留白也要说明留白产生的余味。
- 长片中每 10–15 分钟至少检查一次注意力重新挂靠点。

### 首刷状态机

按 `清楚立足点 → 具体问题 → 可检验预测 → 新证据 → 重新评估/理解` 检查观看路径。它是基于文本证据的预测，不冒充真实观众测试；每项都要写“最可能体验、文本依据、失败条件”。

- **有效悬念**：观众知道人物、目标、风险和自己正在等待的缺口，只是不知道答案。
- **有害困惑**：理解当前行动所必需的身份、地理、因果或时间关系缺失。
- **期待**：必须指向可观察事件和大致回报窗口，不能只写“想继续看”。
- **重新评估**：新证据改变旧事实的解释、人物判断或下一步预测；只增加背景知识不算。
- **理解**：观众能够用一句因果句复述“为什么现在发生这件事”，不要求主题被解释。

## 信息账本

为每个关键事实登记：事实 ID、真实状态、哪些人物知道、观众何时知道、首次证据、误读可能、确认点、对行动的影响。任何揭示如果不改变行动或理解，只是说明，不是转折。

## 宏观情绪曲线

对完整短片、中长片、长片或核心序列，可在 Treatment/结构阶段建立一条 0–10 的宏观压力曲线。节点只来自决定、失败、揭示、身体风险、关系反转、假性安全、释放或余震等真实变化。

| 节点 | 时码/序列 | 事件 | 强度 0–10 | 文本依据 | 呼吸/峰值/反转/余震 | 声音职责 |
|---|---|---|---:|---|---|---|

- 短片通常保留 5–10 个节点；中长片按序列保留 8–16 个宏观节点。
- 开头和结尾不强制归零；没有文本依据时不制造呼吸或释放。
- 标出环境声、动作声、非语言人声和音乐的不同职责；不把每个节点都当作 BGM 点。
- 宏观曲线管呼吸和峰值，首刷体验图管观众的已知、问题、预测、证据和重新理解，三轨节奏校准管可表演时长；三者不互相替代。
- 默认交付节点表和文字判断。用户明确要求时才输出可视化或图像提示词，不声称已生成图片。

## 三轨节奏校准

### 对白轨

- 每个人的句长、词汇、语速、打断、回避、重复习惯是否不同；
- 每句是否在争取、隐藏、试探、拖延或改变权力；
- 朗读时长是否允许停顿、动作和反应。

### 动作轨

- 每个动作拆成准备、启动、受阻/接触、完成和反应；按实际表演计时，不按动词数量计时；
- 同一人物连续动作是否有物理路径，道具、左右手、距离和终态是否接得上；
- 动作是否改变位置、资源、关系、信息或风险；纯忙碌动作删除；
- 对白覆盖动作时，检查演员是否能同时完成，不能就改成先后或停顿。

### 场景文本轨

- 一个句群只承载一个可拍摄动作单位；
- 关键动作前后是否给足观察时间；
- 场景进入是否太早、退出是否太晚；
- 描写是否告诉创作者拍什么，而不是告诉观众该怎么感受。

三轨分别朗读并计时后再叠合；总时长按“不可并行部分相加 + 可并行部分取较长者”估算。若三轨互相抢夺注意力，优先保留当下承担因果变化的轨道。
