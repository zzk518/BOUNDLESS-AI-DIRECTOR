# 质量门槛

## 自检原则

- 主动寻找当前方案失败的条件，不做全通过式打勾。
- 每个问题引用具体句子、场景或因果节点。
- 区分“必须修复”“可选增强”和“个人口味”。
- 自检只给诊断与建议；未经用户确认，不进入下一阶段。
- 修改完成后检查实际交付物，不能以“已修复”的文字声明代替验证。

## 通用检查

### 路由正确性

- 是否正确识别输入成熟度？
- 是否同时识别交付格式与题材方法，且没有让题材覆盖平台/法务硬约束？
- 是否跳过了用户已经完成的阶段？
- 是否把诊断请求误当成从头创作？

### 首刷体验

- 每个序列中，观众是否有一个可说清的问题，而不是只被蒙在鼓里？
- 新证据是否改变预测、人物判断或行动代价？
- 误导是否由可见事实支持，而非隐瞒人物必然会说/做的事？
- 主要承诺是否在登记的回报窗口内兑现、转化或有意留白？
- 是否区分了有效悬念和有害困惑，并为预测写出文本依据与失败条件？
- 关键揭示后，观众的旧判断、下一步预测或人物行动是否至少改变一项？

### 反庸俗

- 故事是否依赖巧合、误会、突发疾病、廉价牺牲或集体温情解决？
- 三个方向是否只是换皮？
- 结尾是否替观众解释主题，或把复杂矛盾抹平？

### 现实逻辑

- 会改变因果、人物、世界、时间或制作资产的信息是否区分原文事实、证据推断、创作提案和阻塞冲突？
- 证据推断是否列出依据和失效条件；未确认提案是否仍留在计划层？
- 人物为什么必须这样行动，而不是采用更简单的办法？
- 空间、职业、金钱、制度和时间条件是否支持行动？
- 关键秘密为什么此前没有暴露？

### 视听可拍性

- 删除“他意识到、他觉得、气氛很悲伤、命运注视着”等不可直接拍摄的结论。
- 用动作、物件、停顿、站位、声音或镜头可见结果替代。
- 不写摄制团队无法执行的矛盾指令。

### 对白

- 朗读对白，删除说明背景和宣讲主题的句子。
- 让人物通过回避、打断、误读和措辞暴露关系。
- 方言只用于节奏和人物，不堆砌难懂词汇。
- 对白轨、动作轨和场景文本轨是否分别朗读和计时，再按可否并行合并，而不是一起凭感觉判断？
- 动作轨是否包含准备、执行、阻力、反应和终态，并与道具、距离和左右手连续？

### 时长与结构

- 将所有段落和场景时长实际求和。
- 检查起止时间是否连续、是否重叠或留空。
- 修改局部时长后，从其他位置等量回收或补足。
- 检查高潮之后是否保留必要的呼吸和余味。
- 宏观情绪曲线的压力、呼吸、峰值、反转和余震是否来自具体事件，且与首刷体验图和三轨时长校准不冲突？

### 连续性

- 核对人物欲望、关键物件、空间位置、伤损状态、时间线和信息知情范围。
- 不得在后续阶段擅自确定前文刻意保留的开放信息。
- 不得为制造伏笔而新增违背人物动机的动作。

### 锁定剧本与交付

- 完整剧本是否能脱离聊天记录独立阅读，并包含版本、格式、目标时长与全部场次正文？
- 是否明确区分 Treatment、场景表、锁定剧本和剧本变更记录？
- 导演交接是否携带锁定剧本版本、事实来源、地域/年代、季节/时间轴、语言/声音文化、空间链、状态链、固定台词、人物/世界锁与禁改项？
- 文档交付是否把锁定剧本独立为 `01-锁定剧本.docx`，没有与导演视觉内容合并，同时保留 Markdown 文本，且没有用附表代替剧本正文？
- DOCX 的标题、正文、对白、表格、页眉页脚及中英文字符是否全部使用微软雅黑？

### 商业广告专检

- 品牌目标、受众、单一主张、客观证据、CTA、平台、必现项和合规边界是否齐全？
- 每个卖点是否有来源；是否出现无法证实的效果、数据、认证或比较？
- 观众能否在一句话内复述主张并知道下一步做什么？
- 美感是否掩盖了证据，故事是否掩盖了品牌归属？

### 30–90 分钟与超长片专检

- 是否存在序列表、主线/关系线/信息线三账和中段重定向？
- 每 10–15 分钟是否有新的注意力挂靠点或回报？
- 90 分钟以上是否有未结清清单，并明确回收、留白或放弃？
- 副线是否真正改变主线选择、人物关系或主题反证？

### 长剧集专检

- 系列发动机能否产生至少 5 个机制不同的分集？
- 人物、世界、时间线、关系、信息和伏笔是否有稳定 ID 与当前版本？
- 正文产生的新事实是否写回差异；计划但未发生的内容是否仍被标为计划？
- 局部修改是否列出传播到哪些集、场、人物状态和伏笔？

## 自检报告格式

对每个发现写：

1. 检查项
2. 证据
3. 风险
4. 最小修正
5. 是否阻止进入下一阶段

结论只能是“通过”“有条件通过”或“不通过”。只要存在会破坏因果、可拍性、体量或连续性的错误，就不得写“通过”。
