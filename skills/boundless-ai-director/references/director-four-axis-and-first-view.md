# 导演四轴与首次观看图

## 四轴决策卡

### 1. IMAGE / 画面

- 视觉命题：能被拍到的变化句，例如“人物越接近真相，门框越把他切得更窄”。
- 重复关系：尺度、遮挡、负空间、材质、颜色或母题。
- 偏离点：高潮何时允许反转构图或光色。

### 2. CAMERA / SPACE / 镜头与时空

- 先写身体、道具和空间的起点/路径/终点，再放摄影机。
- 说明观察距离、机位高度、轴线、屏幕方向、视线、焦段效果和允许的运动。
- 每次移动必须改变信息、权力距离或身体感，不因“画面更活”而动。

### 3. INFORMATION / EMOTION / 信息与情绪

按节拍填写：观众已知、正在问、预测、看到的新证据、重新理解、身体感受、回报/欠账。情绪来自等待时间、距离、遮挡、反应和声音变化，不直接写抽象词。

每个关键揭示另建“信息—情绪合同”：

| 揭示 ID | 揭示前观众判断 | 公平证据 | 强调渠道 | 揭示时点 | 新判断/预测 | 情绪变化的可见依据 | 对后续行动的影响 |
|---|---|---|---|---|---|---|---|

- 信息先后与情绪强弱分别决策；“知道更多”不自动等于“更紧张”。
- 关键证据必须决定使用画面、对白、声音或反应中的主渠道，其他渠道不得重复解释。
- 揭示若不改变预测、人物判断或行动，只能算说明，不能占转折位置。

### 4. ACTION / WORLD / 行动与世界

- 角色以具体动作试图改变局面；动作必须有可见终态。
- 世界规则通过被使用、受阻和付出代价呈现。
- 一条规则如果只靠解释存在，尚未完成导演化。

每条核心规则另建“行动—世界合同”：

| 规则 ID | 可见规则 | 人物尝试 | 世界阻力 | 即时代价 | 结束状态 | 后续回声 |
|---|---|---|---|---|---|---|

- 规则首次出现要让观众看懂怎样使用；第二次至少出现阻力、例外或代价；高潮只能调用已经展示过的规则。
- 每个动作写清 `起始状态 → 企图 → 接触/阻力 → 结果 → 新局面`，并让下一动作从新局面出发。
- 若世界在人物需要时临时改变规则，必须回到剧本层修复，不能用镜头风格遮掩。

## 四轴互锁

每个主要节拍至少写出一条跨轴因果，例如“门只响应死者指纹（行动/世界）→ 观众先看见门开而不知原因（信息/情绪）→ 固定宽景保留人物与门的距离（镜头/时空）→ 指纹污痕成为重复母题（画面）”。四轴若给出互斥要求，按故事功能选择一项，不折中堆叠。

## 首次观看图

| 时段/镜头 | 观众看见 | 观众知道 | 正在问/预测 | 情绪压力 | 新证据 | 重新理解 | 下个镜头任务 |
|---|---|---|---|---|---|---|---|

审计问题：

- 镜头是否让观众新增理解、感受、关系判断或节奏体验？没有则删。
- 观众困惑是有意问题，还是地理/因果拍不清？后者必须修。
- 揭示前是否存在可回看的证据；揭示后是否改变人物行动或观众判断？
- 情绪峰值之后是否有足够余波让观众重组理解？

预测结果必须写成“最可能体验 / 文本与镜头依据 / 失败条件”，不能声称等同真实试映。把观看状态分为：立足点清楚、产生具体问题、形成预测、收到证据、重新评估、完成理解；任一步断裂，都要指出回修到哪个轴。

## 微调回环

发现问题时回到源头：

- 看不懂地理 → 走位/主镜/轴线；
- 不在乎 → 人物行动代价或反应镜；
- 猜太早 → 证据排序与镜头强调；
- 揭示无力 → 前置承诺不足或后果未呈现；
- 节奏拖 → 删除不改变体验的镜头，不先加快所有剪辑。
