# 电影画面语法与视觉证明

本章把导演意图压缩成可检查的画面因果。它只输出文字决策、镜头字段和提示词，不生成图片或视频，也不要求固定画幅、固定镜数或固定模型。

## 1. 先写不可调和状态

每场进入构图前，先用一句话写明：哪两股力量不能同时满足，人物正在执行或拒绝什么动作，场景结束后留下什么后果。若一句话只有情绪形容词而没有行动与后果，暂缓选机位。

线性骨架可写为：

`既有事件/规则 → 人物进入或面对空间 → 执行/拒绝一个动作 → 产生可见后果或未决决定`

每个关键画面都要有一个故事动词，例如等待、遮挡、递交、撤回、越界、辨认、删除、顶住、放弃。只有“氛围”“质感”“高级”的画面不成立。

## 2. 关系压力卡

机位前先填：

- 谁在看谁，谁故意不看谁；
- 谁知道得更多，谁误判；
- 谁准备离开、等待、阻拦或暴露；
- 门、窗、桌、镜面、楼梯、走廊、地面线等怎样限制行动；
- 观众被放在参与者、旁观者、窥视者、被观察者还是盲区中；
- 人与空间谁占主导，主导关系在本镜结束时是否改变。

构图必须服务其中至少一项压力。没有关系压力的对称、留白、框中框或大特写只是装饰。

## 3. 视线流句

每个关键帧或镜组先写一条视线流：

`入口 → 阻挡/加速 → 决定性落点 → 尚未解决的边缘信息 → 离开画面的余味`

示例结构：观众先被门缝亮线吸引，视线被前景肩膀截断，再落到桌下攥紧的手，最后在镜中看见尚未进入对话的人。

若不能用一句话说明观看路线，说明画面很可能在堆元素。视线流允许中断，但中断必须制造误判、迟到的信息或空间压力。

## 4. 真实机位记录

重要镜头必须记录可以落地的摄影机位置：

- 机位所在区域与拍摄轴；
- 高度、人物距离、主体约占画面比例；
- 焦段或视角倾向及其空间后果；
- 前景遮挡、对焦层、视线高度；
- 前/中/后景分别承载什么；
- 主光来自哪个现场事实；
- 移动的起点、终点和停止理由。

不得只写“电影感、压迫、史诗、梦幻”。焦段、高度和运动互相冲突时，优先保留关系压力与空间可执行性。

## 5. 视觉发动机

每个项目或序列选择一个主发动机、最多两个辅助发动机：

- 秩序：轴线、重复、对称或几何规则被建立和破坏；
- 光：可见光源改变身份、信息或行动权限；
- 色：色源在剧情中迁移、衰减或反转；
- 空间：门、层级、遮挡、距离和路径制造叙事；
- 人物状态：姿态、呼吸、动作完整度和表演距离承载变化；
- 尺度/世界：人物与环境比例揭示制度、自然或集体力量；
- 社会调度：多人站位、家具和出入口构成权力几何；
- 主观扰动：焦点、曝光、运动或声画错位表现受限认知。

主发动机拥有构图与剪辑决定权；辅助发动机只补充，不得同时争夺所有镜头。一个方案超过三个发动机时必须删减。

## 6. 综合色与物理色源

先从事实寻找颜色：服装、墙面、天气、实用灯、玻璃/水面/植物反光、时代材料、工作流程产生的污渍。禁止先套全局滤镜再补理由。

建议每个场景记录：

- 两个主要色域；
- 一个过渡色域；
- 一个占画面约 5–15% 的强调色；
- 每个颜色的物理来源和剧情功能；
- 与前后场的连续方式：稳定、室内外过渡、强调色迁移、逐步褪色或有动机的反转。

强调色只有在观众需要看见它时才出现，不把霓虹、青橙或高饱和当默认电影感。

## 7. 捕获介质与单一瑕疵族

一个连续视觉组选择一种捕获基底，例如干净数字摄影、35mm 放映拷贝感、16mm 转录、MiniDV/早期数字、广播监视器再拍、长焦压缩或有动机的超广角见证。选择必须说明它如何改变观看距离、时间感或信息可信度。

同一视觉组最多选择一个主要瑕疵族：干燥尘点/划痕、雨水与湿反光、低输出烟尘、荧光灯脏感、广播噪声、冷凝水、日晒褪色/掉漆等。不要同时堆胶片颗粒、炫光、色差、噪波、烟雾和水滴。

每镜密度预算：2–3 个场景细节、1 个主要动作、1 个次级线索、1 个主光源、1 个主要构图机制。超出预算时按叙事优先级删减。

## 8. 受控变化与反模板镜组

在内部至少比较三个观看路线，再选择最符合故事且近期最少使用的一条。候选之间要改变关系站位、观众位置、空间入口或信息落点，而不是换一组形容词。

镜组不固定为“远景—中景—特写”，也不固定以遗留物收尾。可选结构包括：

- 空间 → 人物 → 证据；
- 秩序 → 异常 → 后果；
- 观察者 → 被观察者 → 盲区；
- 距离 → 突然接近 → 关系重新站位；
- 事件前 → 门槛动作 → 不可逆结果；
- 并行人物碎片 → 同一动作汇合。

第三个关键画面可以是身体恢复、群体反应、关系站位变化、场所继续运行、规则短暂改写或一个改变后的行动。空椅、掉落物、孤零零道具只在剧情确实需要时使用。

同一证明镜组至少在以下字段中改变四项：景别、机位高度、人物/环境比例、构图机制、信息密度、对焦层、光向、人物状态。

## 9. 可选三帧视觉证明组

当用户要求关键视觉、概念证明、提案三联图，或单一序列确实需要快速验证时，输出三帧文字卡；正常分镜不强制使用。

每组要求：

1. 三帧属于同一场景或同一连续事件，不跨场景拼贴；
2. 三帧共享人物、场景、色源和捕获基底锁；
3. 每帧有独立故事动词和不同观看功能；
4. 给出三帧之间的因果顺序与差异字段；
5. 分别输出关键帧提示词，可附外部排版规格，但不声称已经生成或拼接图像。

可根据交付使用 21:9、16:9、9:16 或其他画幅。画幅服务发行和构图，不反过来决定故事。

## 10. 参考隔离

使用参考图时，每张参考最多抽取一个主维度：构图、色彩、介质、主体处理或空间方法之一。其余维度必须重新设计。

不得同时复用人物关系、动作、核心道具、空间骨架、标志性机位和独特色彩组合。交付时写明“保留的一个维度 / 已替换的维度 / 原创性风险”。无法隔离时取消该参考。

## 11. 可选片名、海报与发行视觉文字方案

仅在用户明确提出片名、海报、封面、提案视觉或发行延展时启用。输出仍是文字：

- 片名候选、英文名与一句话钩子；
- 一个决定性的视觉中心，不把分镜拼成海报；
- 标题、署名、辅助信息的层级与安全区；
- 3:4 主海报，以及按需扩展的 16:9、1:1、9:16 版式说明；
- 无字底图提示词与后期准确排字说明。

没有明确请求时不增加海报工作量。

## 12. 视觉证明闸门

逐项寻找失败证据：

- 能否说清不可调和状态、人物动作与后果；
- 构图是否来自关系压力；
- 视线流是否有入口、落点和未决信息；
- 机位是否能在真实空间摆放；
- 色彩是否有现场来源；
- 捕获基底与瑕疵族是否克制一致；
- 镜组是否避开固定景别阶梯与固定遗留物结尾；
- 参考是否只保留一个主维度；
- 提示词是否遵守密度预算；
- 画面是否包含故事动词，而非只提供气氛。

任一关键项无法给出文本证据时，回到关系压力卡或视线流句重做，而不是继续增加风格词。
