# 项目事实圣经与宏观情绪曲线

本文件处理导演工作开始前的两个上游问题：哪些内容已经是真的，以及整片压力怎样变化。它不改写剧本，也不代替逐节拍首次观看图。

## 事实来源等级

每条会影响人物、场景、道具、声音或连续性的设定都标记来源：

1. **原文事实**：锁定剧本、品牌简报或用户明确说明直接给出，可直接进入资产锁。
2. **证据推断**：至少两条现有线索共同支持；记录依据与可能被推翻的条件，不伪装成原文。
3. **创作提案**：制作必须具体化但原文没有答案时，给一套最合适方案、用途与代价；确认后才升级为项目事实。
4. **阻塞冲突**：不同答案会改变剧情、身份、年代、空间或关键资产；确认模式最多提出一个当前真正阻塞的问题，快速模式采用风险最低的临时方案并显著标注。

删除或修改设定时，从当前有效事实重新编译下游资产与提示词。新版不得残留已删除内容、其否定式解释或失效引用。

## 项目事实圣经

只登记会改变可见结果、表演、声音或连续性的字段：

| 区域 | 必要内容 |
|---|---|
| 地域与年代 | 国家/地区、年份或有限年代范围，以及建筑、服装、交通、通讯和技术边界 |
| 季节与时间轴 | 季节、天气、昼夜、故事经历时长及光线状态变化 |
| 语言与声音文化 | 对白语言、口音、阶层/职业造成的语速和措辞差异，具有地域依据的环境声 |
| 世界规则 | 规则怎样被使用、受阻、付出代价；主观暧昧与客观事实的边界 |
| 空间链 | 实际穿越的主要空间、方向、入口、出口和因果衔接；详细平面仍由场景资产处理 |
| 人物制作小传 | 年龄段、地域/族裔、职业生活痕迹、外在目标、关系压力、身体与声音基线 |
| 状态链 | 换装、伤损、湿度、年龄、变形、道具转手、场景破坏的前后顺序 |
| 视觉母题 | 反复出现且承担叙事意义的物件、颜色、材质或空间关系，以及首次出现和回收点 |

每项使用稳定 ID，并记录 `内容 / 来源等级 / 证据或理由 / 版本 / 影响资产 / 当前状态`。没有制作影响的背景知识不进入事实圣经。

## 宏观情绪曲线

情绪曲线表示观众的综合压力或情感冲击，不等于角色自述情绪，也不机械对应每一场。节点必须来自真实变化：决定、失败、揭示、身体风险、关系反转、假性安全、释放或余震。

### 节点表

| 节点 | 时码/序列 | 可见事件 | 观众压力 0–10 | 变化方向 | 文本依据 | 呼吸/峰值/反转/余震 | 声音或音乐职责 |
|---|---|---|---:|---|---|---|---|

- 短片通常保留 5–10 个有效节点；中长片按序列保留 8–16 个宏观节点，必要时再为重点序列建局部曲线。
- 开头和结尾不强制归零；没有文本依据时不制造假性释放。
- 至少辨认一个真实呼吸窗口，或明确说明本片为何持续加压。
- 声音列区分环境底、动作声、非语言人声和音乐；不是每个节点都需要 BGM。
- 结构、关键转折或结尾变化时重算；仅改措辞且节拍不变时不重算。

## 与首次观看图的分工

- **宏观情绪曲线**检查整片呼吸、升级、峰值、释放和余震。
- **首次观看图**检查每个节拍的已知、问题、预测、证据与重新理解。
- **节奏/分镜时码**落实镜头实际时长和覆盖密度。

三者必须互相校验。情绪峰值没有可见事件或信息变化则回到剧本；首刷图出现理解断裂则回到信息/空间；时码容纳不了等待、动作与反应则回到节奏规划。

默认交付节点表和文字判断。只有用户明确要求图表时才提供可视化说明或图像提示词；不得把计划中的曲线图声称为已经生成的图片。
