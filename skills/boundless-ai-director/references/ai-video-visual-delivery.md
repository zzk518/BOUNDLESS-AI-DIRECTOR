# AI 视频精简视觉交付与提示词格式

当用户要求“视觉文档”“AI 视频视觉方案”“资产与分镜/视频提示词”或同义任务时，默认使用本合同。内部仍可完成必要的剧本、空间、连续性与导演判断，但对外视觉文档只保留直接用于 AI 图像和视频生成的内容。

## 文档范围

`02-导演视觉方案.docx` 默认只包含：

1. **总体影调提示词**；
2. **人物、场景、道具资产提示词**；
3. **分镜图/关键帧提示词**；
4. **4–15 秒视频提示词**。

开头最多保留一张极简项目卡：项目名、剧本版本、目标时长、画幅、目标图像/视频工具和提示词版本。资产 ID、场景 ID、镜号和视频段 ID 直接写在对应提示词标题中，不另建冗长台账。

四轴分析、首次观看图、宏观情绪曲线、关系压力、走位推演、连续性表、声音剪辑方案和执行清单默认作为内部编译依据，不进入视觉文档。用户明确要求“完整导演阐述”“制作圣经”“声音剪辑”或相应附表时再单独追加，不污染精简主文档。

## 提示词共同原则

- 先写会改变画面的决定，再写平台参数；不以空泛画质词填充篇幅。
- 每条提示词可独立复制，必要的总体影调锁压缩后写入资产、分镜和视频提示词，不能只引用一个模型看不到的章节标题。
- 相机、镜头或胶片型号只有在对应到透视、景深、高光、颗粒、色彩或操作方式时才写；没有实际作用时使用“捕获介质＋镜头效果”描述。
- 色彩默认写“主色域／辅助色域／强调色＋物理来源”。只有用户已有确定色板或目标工具能可靠读取色值时才附 HEX；百分比是美术分配意图，不宣称生成模型能精确执行面积比例。
- 不用摄影师、导演或具体影片名称代替可见方法。将参考拆成构图、观察距离、光线、色彩、材质、表演和运动等可执行字段。
- 准确文字、商标、UI 和产品标识留给实拍或后期合成。
- 默认只输出目标工具最适合的一种提示词语言：Midjourney 图像提示词优先英文，中文视频模型优先中文。用户明确要求双语时再逐项对齐输出，避免无意义地把文档翻倍。

## 1. 总体影调提示词

按以下顺序组织成一个可复制段落：

```text
[媒介、年代与现实程度]
+ [构图与观察距离]
+ [捕获介质、镜头效果、景深]
+ [主色域、辅助色域、强调色及物理来源]
+ [主光源、方向、硬软、色温关系、反差]
+ [暗部/高光曲线与后期处理]
+ [皮肤、布料、金属、空气等材质表现]
+ [允许的颗粒或单一瑕疵族]
+ [必须避免的本项目高风险项]
+ [目标工具参数]
```

这里的 `+` 只表示字段顺序，最终提示词使用自然语言、逗号和分号连接，不输出公式符号。总体影调必须能压缩为 2–5 句，不写长篇美学阐述。

## 2. 资产提示词

每个资产使用一张简洁卡：

````text
### [资产 ID]｜[资产名/状态]
用途：[人物母板 / 无人场景底板 / 道具母板]
依赖：[已确认参考图或上游资产 ID；无则写“无”]
提示词：
```prompt
[可直接复制的完整提示词]
```
````

### 人物

`角色职责与年龄 → 身份锁 → 脸/发/肤 → 身体比例与姿态 → 服装分层、材质、磨损和左右锚点 → 中性母板布光/背景 → 总体影调中的材质锁 → 禁变项 → 参数`

人物母板优先准确身份和服装固有色，不让戏剧环境光污染定妆。剧情状态只有会改变身份识别或连续性时才单独立项。

### 场景

`场景功能与时空 → 尺度和平面地理 → 入口、路径、固定陈设 → 主材质与使用痕迹 → 时间天气 → 主光源、方向和物理色源 → 观察机位/镜头效果 → 无人空间底板 → 禁入元素 → 参数`

同一场景先生成无人底板；需要多角度时保持地理、固定陈设、光向和材质不变，只改变机位。

### 道具

`剧情功能 → 真实尺寸参照与比例 → 结构、连接方式和可动部件 → 材质、固有色和磨损 → 左右非对称、文字/图案方向和当前状态 → 单件产品档案照布光/背景 → 禁止人物、手和额外配件 → 参数`

普通一次性道具不单独生成母板。

## 3. 分镜图/关键帧提示词

每个需要生成的画面使用：

````text
### [KF ID]｜场景 [SC ID]｜镜头 [SH ID]｜[首帧/尾帧/关键帧]
依赖：[角色、造型、场景、道具资产 ID]
提示词：
```prompt
[主体身份与服装]；[动作开始或刚结束的可见终态]；[人物、道具、前中后景与空间位置]；[景别、角度、机位、镜头效果和景深]；[总体影调中的色彩、光线、曲线、材质与颗粒]；[连续性锁与本镜高风险约束]；[参数]
```
````

分镜提示词必须描述一个可冻结的瞬间。心理、主题解释和镜头之外的信息不得写入。

## 4. 视频提示词

优先将同一场景、时码相邻且状态连续的镜头合并成 12–15 秒；无法安全合并时使用 4–8 秒。每条采用：

```text
### [VID ID]｜[4–15 秒]｜场景 [SC ID]｜覆盖镜头 [SH IDs]
依赖：[首帧/尾帧/资产 ID]
总体锁定：[人物身份、服装、场景地理、时间天气、光向、色彩和材质]
[00:00–00:xx] [景别/机位]；人物起点→主要动作→终点；摄影机行为；环境运动；对白/声音（工具支持时）。
[切点 00:xx] [CUT / MATCH / SOUND BRIDGE]：[可见切点依据]。
[00:xx–00:yy] ……
末态：[下一段可以直接承接的画面、动作、道具和声音状态]
约束：[只列本段真实风险；身份稳定、肢体自然、无闪烁、无无关人物/文字/水印]
```

图生视频时不重复描述已经锁定在输入图中的静态外观，只写运动、节拍、终态和风险；文生视频才补齐完整主体与环境。

## 精简验收

- 四类提示词齐全，且没有混入长篇导演说明；
- 资产与镜头使用稳定 ID，分镜提示词能找到上游资产；
- 总体影调已被压缩并落实到各类提示词，不靠作品/作者姓名替代；
- 人物、场景、道具状态在关键帧和视频段中一致；
- 每个镜头只属于一个主视频段，视频段不跨场景且为 4–15 秒；
- 每条提示词可直接复制，没有模板占位符、历史补丁和互相矛盾的参数。
