# 制作路由与专门交付合同

本 Skill 在所有路由中只交付文字。下文“资产”“关键帧”“视频段”均指资产设定、分镜描述、提示词或人工制作任务卡，不代表已生成媒体。

## 叙事短片

- 核心：一次人物选择和完整观看回报。
- 导演交付：四轴定调、首刷图、节奏/走位、文字分镜、连续性、资产设定、关键帧提示词、视频提示词、声音剪辑文字方案。
- 风险：用反转代替铺垫；漂亮镜头多于故事功能。

## 竖屏剧情短剧

- 9:16 原生设计；脸、手、关键道具和行动落在安全区，空间用纵深而非横向远景。
- 首秒建立问题，3 秒内有可见变化，单集有回报与集尾牵引。
- 每集交付增加：钩子镜、关系状态差异、集尾连续性、字幕安全区和手机端可读性检查。
- 不为完播率牺牲地理和人物逻辑；字幕是剪辑层，不要求生成模型直接渲染准确文字。

## 商业广告 / 品牌片

### 输入合同

品牌目标、受众、单一主张、可证实证据、CTA、平台/画幅/时长/版本、必现品牌资产、产品真实素材、法务/合规和禁用项。

### 导演结构

`钩子/问题 → 主张 → 具体演示或证据 → 感受回报 → 品牌/CTA`

- 每镜标注广告功能：Hook、Claim、Proof、Benefit、Brand、CTA 中之一。
- 产品比例、颜色、材质、接口、商标和文字属于事实锁；生成不可靠时改用真实素材、摄影或后期合成。
- 交付增加：证据镜清单、产品英雄镜、品牌安全区、法务占位、横竖版适配、真实拍摄/生成/合成分工。
- 不捏造功效、数据、排名、认证、证言或前后对比。

## 网大 / 中长片 / 长片

- 先按序列做四轴与节奏，不直接逐镜铺满全片。
- 保持题材回报间距和中段重定向；动作段先建立地理，文学段保留观众解释空间。
- 交付分层：全片导演圣经 → 序列卡 → 场景走位 → 分镜批次 → 状态差异，避免一次输出不可维护的巨表。

## 系列 / 长剧集

- 在剧本长期资产之上增加视觉连续性圣经：角色造型版本、场景底板、光向、道具状态、伤损/湿度、地理与屏幕方向。
- 每集只生成当前集需要的资产增量；复用已批准资产 ID，不重新描述为新版本。
- 交付增加：集视觉主题、允许偏离点、资产新增/复用/退役表、跨集状态差异、回滚版本。

## 路由冲突

格式容器只控制画幅、时长、安全区和必交付块；题材控制戏剧承诺；主导演方法控制工艺。广告合规与品牌事实高于风格，竖屏安全区高于原横构图，但两者都不应抹掉故事功能。
