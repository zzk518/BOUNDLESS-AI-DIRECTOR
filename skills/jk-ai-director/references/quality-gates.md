# 质量门槛

## A. 导演与节奏

- [ ] 定调覆盖画面、镜头/时空、信息/情绪、行动/世界四轴；
- [ ] 首刷体验图标明观众已知、问题、预测、证据、重新理解与回报；
- [ ] 定调包含构图、走位、机位、光线、剪辑、声音、视角和视觉母题；
- [ ] 每个方向的差异来自镜头语言，而不是类型标签；
- [ ] 每个镜头能说明观众新增的理解、感受、关系或节奏功能；
- [ ] 场景时码首尾相接，总和精确等于目标时长；
- [ ] 镜头密度与情节强度匹配。
- [ ] 首刷预测逐项写出最可能体验、文本/镜头依据和失败条件，不冒充真实试映结论；
- [ ] 关键揭示有“揭示前判断—公平证据—新判断—行动影响”，核心规则有“尝试—阻力—代价—终态—回声”。

### 风格融合

- [ ] 主/辅/强调方法的权重、适用范围和拥有的工艺旋钮明确；
- [ ] 用户锁定、格式、题材、主方法、次级风格的优先级无倒置；
- [ ] 固定/手持、深/浅景、长镜/快切、自然/表现光色等冲突已逐项裁决；
- [ ] 不用导演名字替代具体镜头决定，也不复刻具体影片镜头。

## B. 分镜

- [ ] 镜号连续，无重复和漏号；
- [ ] 起止时码连续，无重叠和空洞；
- [ ] 摄影角度、景别和备注可同时执行；
- [ ] 每镜写清起始状态、运动和结束状态；走位先于机位；
- [ ] 人物动机、动作、位置和道具状态连续；
- [ ] 180 度线、视线和运动方向有明确依据；
- [ ] 画面内容没有心理解释或作者结论；
- [ ] 修改说明与实际表格一致。

## C. 视觉资产与 MJ

- [ ] 人物/场景/道具 ID 完整，场景—道具映射齐全；
- [ ] 同一人物的外貌、服装和标志物逐条一致；
- [ ] 资产锁包含会被提示词复用或审核的身份、地理、光向和状态字段；
- [ ] 每条图像提示词包含任务、身份锁、动作终态、场景地理、机位、光向、材质、风险约束和参数；
- [ ] 中英语义对齐；
- [ ] UI/门牌等准确文字改为后期叠加，不要求模型直接生成。

## D. 视频提示词

- [ ] 已识别目标工具控制面；不了解时使用平台中性合同，不虚构功能；
- [ ] 每条生成时长为 4–15 秒；在同场景且连续性成立时尽量装到 12–15 秒，场景纯度优先于凑满时长；
- [ ] 每条主视频提示词只包含一个场景 ID；跨场景切换必须拆段；
- [ ] 分镜覆盖率为 100%，每个分镜只出现在一个主视频提示词中；
- [ ] 多镜提示词的每个切镜点都标出时间、景别、机位和空间锚点；
- [ ] 起幅、走位、按秒动作和明确终态均可拍摄；
- [ ] 对白与口型时段匹配；无对白明确标注；
- [ ] 画内、画外、配乐/旁白/字幕层已正确分类；
- [ ] 与前后镜头至少有一项可验证的衔接逻辑；
- [ ] 中英版逐项对应；
- [ ] 约束只针对本段真实风险，没有过长通用禁词表。

## E. 制作路由

- [ ] 广告具备品牌目标、受众、主张、证据、CTA、必现资产和合规边界；
- [ ] 广告每镜标注 Hook/Claim/Proof/Benefit/Brand/CTA，真实产品高风险内容已路由到实拍/合成；
- [ ] 竖屏短剧为 9:16 原生走位并通过手机端可读性、安全区、首秒问题和集尾牵引检查；
- [ ] 网大/长片按序列交付，剧集资产增量和跨集状态差异可追踪。

## F. 文字制作交接

- [ ] 资产设定、关键帧提示词、视频提示词、声音和剪辑任务卡有稳定 ID、版本与依赖；
- [ ] 未覆盖旧版本，失败记录含主要失败轴与单一修改变量；
- [ ] 相同根因三次失败后已改镜头/关键帧/输入模式，不继续堆提示词；
- [ ] 所有状态均为文字计划或人工回填；不声称已提交生成、已创建节点或已产出媒体。
- [ ] “不用确认/直接做”仅跳过文字创作阶段确认，不被解释为外部平台操作授权。

## G. 禁止项扫描

逐条搜索并清除：

- 中文空词：令人叹为观止、令人惊叹、视觉盛宴、完美呈现、震撼人心、美轮美奂、无与伦比、惊艳、绝美；
- 英文空词：breathtaking, stunning, captivating, mesmerizing, cinematic masterpiece, visual feast, seamlessly, flawlessly, cutting-edge, next-level；
- 心理词：感到、意识到、内心、仿佛、似乎、悲伤、恐惧、愤怒（除非作为诊断标签，不得进入生成提示词）；
- 不可见气味、未拍到却被当作可见事实的画外状态变化、无依据的品牌或产品事实。

## H. 发现问题后的处理

1. 标出镜号/资产 ID 与冲突字段；
2. 只修改最小范围；
3. 重新计算所有受影响时码；
4. 回查前后镜的状态和衔接；
5. 再次扫描禁止项；
6. 以实际文件或表格为准，不接受“已修复”的文字声明替代验证。
