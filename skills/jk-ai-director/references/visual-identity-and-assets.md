# 视觉资产锁与图像提示词

视觉身份不是相机型号清单，而是一组跨场景可复用、可审核的约束。只保留会改变画面或生成一致性的字段。

## 全片视觉规则

记录：画幅、构图命题、允许的景别范围、摄影机运动集合、主/辅焦段效果、光源动机、光向、色彩关系、材质/颗粒、表演尺度、时代禁入项、允许偏离的转折点。

空间、时间或叙事层级变化明显时建立视觉群组。每组只写与全片规则不同的字段，并保留人物身份、画幅和连续性锚点。

## 人物与造型锁

```yaml
character:
  id: CHAR-001
  visible_identity: "脸型、眼距、鼻口、发际线、肤色与独特痕迹"
  body: "身高区间、体型、肩胯比例、步态"
  hair: "长度、分线、湿度、束发状态"
  performance_baseline: "站姿、视线、手势、动作速度"
  must_keep: []
  must_avoid: []
wardrobe:
  id: FIT-001
  layers: "由内到外逐层记录"
  closure_state: "扣合/卷袖/领口"
  material_color_wear: "材质、颜色、磨损"
  footwear_accessories: ""
```

过去版本、替身、复制体必须列相同锚点与差异锚点，不靠名称区分。

## 场景锁

固定：尺度、平面分区、门窗相对位置、角色可走路径、固定陈设、主材质、使用痕迹、主光源与方向、时间/天气、环境色、可移动元素、不得出现元素、参考图槽位。场景图应先生成无人的空间底板，再绑定人物。

## 道具锁与状态

固定：ID、尺寸参照、形状、材质、颜色、磨损、文字/标识处理、可动部件、持有人、左右手、朝向、填充量、首次状态、每次变化、末次状态。准确品牌、文字、屏幕默认使用真实素材或后期合成。

## 连续性审查轴

每镜至少检查：脸、发型、服装分层、道具/左右手、污渍/伤损、光向、时间、天气、空间地理、屏幕方向、视线、机位高度、色彩关系、焦段观感。只把会被提示词复用或审核的问题写入资产表。

## 图像提示词结构

按顺序写：

1. 画幅与镜头任务；
2. 主体身份锁、服装锁、可见动作/终态；
3. 场景地理、前中后景和道具位置；
4. 景别、机位、焦段效果、景深；
5. 光源、方向、硬软、反差和色温关系；
6. 色彩、材质、时代、颗粒；
7. 必须保持与具体风险约束；
8. 目标工具参数。

英文版与中文版逐项一致。避免 `masterpiece, stunning, 8K, cinematic` 等不改变决定的词；把“压迫”改成低顶棚、门框切割、人物贴边、顶光等可见关系。

Midjourney v7 默认参数仅作平台适配：人物/道具 `--ar 1:1`，场景/分镜按项目画幅；`--v 7.0 --style raw`。`--no` 只列该图真实高风险项，不使用过长通用禁词表。

## 关键帧闸门

- 身份、服装、光向、场景地理与前后镜一致；
- 画面说明动作将如何开始或刚如何结束；
- 景别、机位和走位能同时成立；
- 真实品牌产品比例、标识和颜色不得靠生成模型猜测；
- 未通过的关键帧不能进入视频生成。
